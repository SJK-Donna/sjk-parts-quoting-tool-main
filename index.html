Users

Everyone signs in with their own email and password. Sales open in the sales tool (Find a part · Quote). Admins open in this admin console and can change costing, passwords, the price list and users.

Users can be managed here once you're signed in as an admin and the parts-api server is up.

Parts data

Prices come from Club Car's dealer price quotes for SJK Guahan (dated 9 Aug 2026, USD, "Unit Price" = SJK's buy price) and the 2025 Minibus Complete Spare Parts Catalogue (FCA China, valid 1 Dec 2025 – 31 Dec 2026). Cart fitment comes from the parts-book upload lists in each model folder.

Upload a new price list

Choose the parts_data.json built from Club Car's new price files. It replaces the price list for everyone straight away (the last 5 versions are kept). Dealer costs stay behind sign-in — the file is never published on the website.

How the cost is worked out

  1. Buy price in USD from the price list. China (Minibus) parts add an origin fee, because FCA prices exclude export and wood-packing charges.
  2. Freight: either a % of the buy price, or USD per kg × weight. Weights come from a default per category, which you can change on each quote line.
  3. Insurance % of buy price + freight gives the CIF value — the value Customs taxes on.
  4. Duty and brokerage & port charges are % of CIF. Misc / contingency is a % buffer on top.
  5. Converted at the forex rate + buffer. That gives the landed cost.
  6. Selling price = landed cost ÷ (1 − margin), rounded up. 12% output VAT is added on top where shown.

Import VAT is creditable input VAT for a VAT-registered company, so it is left out of cost by default. Turn it on in Costing setup if you want it included.

Categories are assigned by keywords in the Club Car description, so a few parts may sit in a near-neighbour category. Search always covers every category.
